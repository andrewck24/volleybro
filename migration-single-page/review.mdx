<Deviations>

1. **分頁檔由 collection 收錄，而非 publish 產生 import。** Proposal 寫的是「publish 依目錄中的檔案產生 `index.mdx` 的本文」。改用第二個 fumadocs collection 收錄 `proposal.mdx` 與 `review*.mdx`、由 route 渲染，作者不寫任何 import，本機開發伺服器也不需要先 publish 才能讀到草稿；每個分頁仍在自己的呼叫堆疊上渲染，一個分頁出錯不影響其他分頁。
2. **`cf` 以 `pnpm dlx` 取用。** Proposal 與 ADR-0097 原寫 devDependency。實際安裝時 `cf` 帶進約 100 MB 的 `workerd` 執行檔與上千行 lockfile 變動，CI 與每次部署都會下載；改成只在 gate 需要時下載並快取，版本範圍仍是 `^1.0.0-beta.5`。
3. **`cf` 需要先以 Worker 名稱查出 tag。** `builds triggers list` 必須帶 `--external-script-id`，gate 先讀 `blueprint/wrangler.toml` 的 Worker 名稱，再以 `workers scripts search` 取得 tag。
4. **轉換腳本在合併後才推上 store。** 範圍第 6 點的轉換照做，但 store 的每次 push 都會以 `dev` 的舊程式建置正式站，舊程式把 `proposal.mdx` 當成缺 title 的頁面而失敗，所以本機以 `--local` 轉換並驗證，store 在合併後轉換。
5. **G1 基準重新 publish 一次。** store 上本頁的 G1 publish 是拆檔前的單一 `index.mdx`，新的凍結檢查無從比對，所以以 `--gate G1` 用拆檔後的檔案重新記錄；`proposal.mdx` 是 G1 內容的逐字搬移，未改一字。
6. **`CONTRIBUTING.md` 沒有修改。** 範圍第 7 點列了它，但它從未提到 `Migration` trailer，trailer 規則只寫在 `WORKFLOW.md`。
7. **review 走了三輪。** 第一輪的發現分屬不同根本原因，沒有連續兩輪同一根本原因，未換做法。

</Deviations>
