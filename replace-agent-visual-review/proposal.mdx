## Scope

1. 移除 WORKFLOW、Blueprint agent instructions 與直接相關 Feature 中要求 Agent 常態逐頁 browser verification 的規則；保留開發者 G1／G2 human acceptance、開發者 dev-server 檢視選擇、既有 Preview publication、build/render error 與部署 identity 的 fail-closed 檢查。
2. 修改 trusted Preview workflow：只在同一 G1 或 G2 snapshot 確有 `design.tsx` 時，對該 Change 跑一次 route proof。proof controller 由 trusted `main` workflow revision 執行；依本次 build receipt 驗證同一 source SHA、integration SHA、store SHA 與 Change input hash；先確認靜態 HTML 含 `載入設計稿…`，再等待 loader 消失；收集 pageerror 與 console error，並拒絕 MockupFrame error fallback。缺少 receipt、route、mount 或匹配 identity 一律失敗，不上傳該次 artifact。
3. 在 `InteractiveFlowchart` 共用元件處理長 label 換行、節點尺寸與碰撞；元件回歸測試驗證 SVG label lines 與 node/viewBox geometry，維持既有 light／dark semantic token 對應。
4. 新增 Blueprint MDX guard，拒絕 SVG `<text>` 開標籤後立即換行的來源形狀；不掃描或改寫已封存頁面。
5. 不改 DecisionRecord schema，不重寫已接受的 Proposal，不移除 Preview 或開發者 gate。
