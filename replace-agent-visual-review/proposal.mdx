## Scope

1. 移除 WORKFLOW、Blueprint instructions 與相關 Feature 的 Agent 常態逐頁 browser review；Impeccable critique／distill 僅檢視與修訂文字，只有開發者認為圖表或畫面難理解時才另開 browser 檢視。保留 G1／G2 human acceptance、開發者預覽選擇、既有 Preview publication 與 build/render error、部署 identity 的 fail-closed 檢查。
2. 說明 mockup 按需製作與留存：小型文案、色彩、間距或既有元件重排使用 dev preview 和少量前後截圖；新互動、狀態轉換或動畫可在 grill／G1 按需使用隔離 prototype。決定後只留必要截圖／影片、關鍵狀態與選擇理由；只有仍需反覆比較時才保存互動 mockup，優先共用元件搭配少量資料。不要求每份 Proposal 建立或長期保存 `design.tsx`。
3. 修改 trusted Preview workflow：只有 G1／G2 snapshot 本身含 `design.tsx` 時，才對該 Change 執行一次 route proof。trusted `main` workflow controller 依 receipt 核對 source SHA、integration SHA、store SHA 與 Change input hash；先確認靜態 HTML 有 `載入設計稿…`，再等待 loader 消失；收集 pageerror／console error，拒絕 MockupFrame error fallback。缺少 receipt、route、mount 或相符 identity 即 fail closed，不上傳該 artifact。這是 runtime 驗證條件，不是新增 mockup 的要求。
4. 在 `InteractiveFlowchart` 共用元件修正已知長 label 換行、節點尺寸與碰撞，並用元件回歸驗證 SVG label lines、node/viewBox geometry 與既有 light／dark semantic tokens；新增 MDX guard，拒絕 SVG `<text>` 開標籤後立即換行。這些檢查取代已知元件缺口，不恢復逐頁手動點擊或整站巡檢；不掃描、改寫或刪除已封存 mockup。
5. 不改 DecisionRecord schema、不改寫已接受的 Proposal，不移除 Preview、G1／G2 human acceptance 或 accepted snapshot freeze。
