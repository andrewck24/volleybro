<Proposal>

<TLDR>
`/changes` 在改成兩道 gate 時退化成一串標題連結，沒有日期、狀態，也沒有排序；Blueprint 的 `/` 則只是轉址到 `/changes`，連預覽工具都判斷不出 server 已經啟動。這個 Change 讓兩種格式的 Change 都用 `startedAt` 與 `archivedAt` 標日期，`/changes` 改回卡片、由新到舊排在同一條時間軸上，並替 Blueprint 建一個真正的首頁。
</TLDR>

| | 現在 | 之後 |
| --- | --- | --- |
| `/changes` | 標題連結清單，單頁格式依 slug 排序，舊格式另外排在後面 | 卡片：標題、描述、狀態、日期、capability；兩種格式混排，由新到舊 |
| 單頁格式的日期 | `publishedAt`、`mergedAt`；`mergedAt` 在合併前 publish 後一直是 null | `startedAt`（第一個 commit）、`archivedAt`（落地 `dev`）；合併後重新 publish 一次 |
| `/` | 轉址到 `/changes`，回應 307 | 首頁：簡短介紹與 Features、Changes、Design System 三個入口，回應 200 |

## 範圍

1. `facts.json` 改用 `startedAt` 與 `archivedAt`：`startedAt` 取這個 Change 第一個 commit 的時間，還沒有 commit 時取第一次 publish；`archivedAt` 取代 `mergedAt`。store 分支的 commit 時間曾被整批匯入與 rebase 改寫，所以不採用。
2. `WORKFLOW.md` 合併後的收尾加上一步：從 `dev` 重新 publish 這個 Change，讓 `archivedAt` 寫進 `facts.json`。已合併但還沒有 `archivedAt` 的 Change 在本 Change 內補發。
3. `/changes` 以卡片呈現，兩種格式依 `archivedAt ?? startedAt` 由新到舊排序。
4. Blueprint 首頁 `/`。

還沒完成的舊格式 Change（仍在 proposing 或 discussing）沒有 `archivedAt`，照 `startedAt` 排序。

這次沒有要你親自執行的測試，全部由 agent 完成。

<ReviewFocus>

1. `scripts/change-page.js` 的 `changeFacts`：`startedAt` 取第一個 commit 的 author date，沒有 commit 時退回第一次 publish；`archivedAt` 取落地 commit 的時間。
2. `blueprint/src/lib/changes-index.ts`：兩種格式放在同一條時間軸，依 `archivedAt ?? startedAt` 由新到舊排序，沒有日期的草稿排在最後。
3. `blueprint/src/app/page.tsx` 與 `ChangeCard.tsx`：新首頁與卡片的呈現。

</ReviewFocus>

<Deviations>

1. **`startedAt` 改為第一個 commit。** 重新 publish 時發現，store 分支的 commit 時間曾被整批匯入與 rebase 改寫：照原本的定義，`two-gate-workflow` 會在它合併之後才開始，`triage-state-mapping` 也會早了兩天。S4 經你授權走 Ingest 改寫，ADR-0078 的內文同步修改。squash 合併的 Change 只剩 squash commit，所以開始時間等於完成時間，和它的 commit 數無法得知是同一個原因。
2. **第 3 輪 review 前換了做法。** 第 1 輪兩軸都發現 Features 頁與註解還寫著舊定義，第 2 輪又找到過時的註解與測試。三者的 root cause 相同：`startedAt` 改了定義，卻沒有同步到每一處提到它的地方。於是不再照 reviewer 點名逐一修補，改為把所有提到 `startedAt` 與 first publish 的地方全部找出來，逐一核對。換做法之後的第 3 輪回到全範圍審查。

3. **G2 時追加的兩項。** 你在 G2 接受 Review 時，另外要求：
   - Change 的數字改用不同顏色的徽章，新增與刪除分開，頁首與卡片都要有；之後依你的意見，`+`／`−` 只用圖示表示，並替螢幕閱讀器補上「lines added／removed」的隱藏文字。文字色往前景色混合，深淺兩種模式的對比都在 4.5 以上，這幾個色調成為 Blueprint 的 theme token（`info-text` 等）。
   - 用 `ui-ux-pro-max` 重新設計首頁：Swiss 極簡、靠左對齊的網格，三個入口磁磚各有圖示，標題只在空白處換行。我另外加上 Features、Changes 的即時數字與「最近的 Change」，請見「需要你決定」第 3 項。

</Deviations>
