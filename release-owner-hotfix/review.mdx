<AfterRelease>

這裡的操作時點是本批 G2 通過、PR checks 綠燈並合併之後，不是要求你現在部署。

1. Agent 與你核對 GitHub repository variable `RELEASE_OWNER_LOGIN` 的實際 owner；read-only 授權使用 job-scoped native token，不需要另外增加 PAT Checks 權限。既有 PAT 寫入身份與權限仍需核對。
2. 配置 `production-release-review` 的 required reviewer。單人模式可以使用 owner 自己，不能啟用 `Prevent self-review` 導致自我驗收被擋住；不是移除 protected environment。
3. 依原 release-train Shard 4 的一次性清單繼續 baseline／平台 inventory、演練、integration cutover、dependency live proof 與首次正常發布。本 Change 取代其中第二位人類 hotfix approval 前置，其他未完成義務不省略。
4. 真正 hotfix 時，完成獨立 Agent review 與 CI，由 owner 明確授權 exact PR／head dispatch；你在 candidate 與 production 各做必要 protected QA，成功後才 tag。Merge-back 優先交 Agent，合併仍需明確授權。

合併 tooling 不代表發布成功，不刪 dev、不重設 DB，也不提前開啟 automation flags。

</AfterRelease>
