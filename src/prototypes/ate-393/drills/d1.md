Creating a team whose nickname is already used by another team must fail. Assume the team repository can answer `existsByNickname(nickname: string): Promise<boolean>`. When the requested nickname is taken, respond HTTP 409 using the existing conflict-type AppError (find it in src/entities/errors; use reason `TEAM_NICKNAME_TAKEN`, declared locally in the prototype if the reason enum lacks it). Teams without a nickname skip the check. Nothing may be written when the nickname is taken.
