The transaction runner can now fail with an outcome-unknown transient error (the commit may or may not have happened). Model it as the existing transient AppError category (find it in src/entities/errors). Retry the whole create-team transaction up to 2 more times on that error only. If all attempts end outcome-unknown, respond HTTP 503 TRANSIENT. Other errors are not retried.
