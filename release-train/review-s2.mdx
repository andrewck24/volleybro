<AfterRelease>

本節的 release 指本批 tooling PR 交付後；不是宣稱 app 已發布。

1. 重新盤點 refs、open PRs、worktrees 與 pending changesets，保留其他開發者新合併的 dev 內容；不重寫共享歷史。
2. 先解除舊 main merge 直接部署 production 的連動，透過正常受檢查 PR 保留 dev 歷史整合至 main，再一起調整 GitHub default／required checks、Blueprint production branch／deploy hook 與 main integration alias。
3. Read-back project／team、DB `test`、OAuth callbacks、domain protection、required reviewers 與 credential scopes，演練完成才啟用 automation。新網址未設定前不宣稱可用。
4. 由 Changesets 計算首次實際版本，不硬指定版本；version PR 最新 checks 通過並取得合併授權後，固定 SHA candidate → 必要 QA → promote → production smoke／QA → exact-SHA tag／Release。
5. 成功發布、dev 已為 main ancestor 且沒有活 PR／worktree／設定引用後才刪除 dev。舊 sync 工作確認淘汰後再更新其相關 operational issue；本 Change 的 hotfix 與 dependency shards 仍待交付，tracking parent 不關閉。

</AfterRelease>
