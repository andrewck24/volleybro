<TLDR>
判斷型規則已搬進只在 review 時讀的 `CODING_STANDARDS.md`，寫作規範落到 `CONTRIBUTING.md` 與 `docs/agents/blueprint.md`，`AGENTS.md` 成為唯一指引檔、`CLAUDE.md` 只含 `@AGENTS.md`。`check:workflow` 新增五類檢查與一個警告，元件字串的反引號渲染為 inline code，ADR-0045 拆成 ADR-0061 到 ADR-0067，G1 改為確認對話總表（ADR-0060）。8 條 scenario 都有會在缺少實作時失敗的測試並全數通過；兩軸 review 三輪後到達 fixed point。唯一未綠的是 `verify:all` 的 app-build lane：本機與 worktree 都沒有 `.env.local`，以佔位的 `MONGODB_URI` 重跑 `pnpm build` 成功，本 Change 也未觸及 `src/`。
</TLDR>

## Acceptance scenario 結果

8 條全數通過，每條都有會在缺少實作時失敗的測試。

| # | Scenario | 測試 |
| --- | --- | --- |
| 1 | Pre-PR reviewer brief 引用 `CODING_STANDARDS.md`、不再引用 `CONTRIBUTING.md` | `check-workflow.test.js`：Pre-PR gate section missing CODING_STANDARDS.md／still cites CONTRIBUTING.md |
| 2 | `CLAUDE.md` 不是剛好 `@AGENTS.md` 時失敗 | CLAUDE.md content other than the guidance import／missing CLAUDE.md |
| 3 | `AGENTS.md` 出現章節編號時失敗 | section-number reference（`§` 與 spelled-out 兩種） |
| 4 | 頁面標題形狀不符時 gate 失敗 | `checkGateTitles` 四個案例，含 YAML 加引號的標題 |
| 5 | 未 commit 的 record 或分支領先 upstream 時 gate 失敗 | `checkGateBranchState`：uncommitted records／ahead／no upstream |
| 6 | 元件字串的反引號渲染為 inline code | `render-inline.test.tsx`、`Scenario.test.tsx`、`RiskTable.test.tsx` |
| 7 | retired-authority 檢查涵蓋 `CODING_STANDARDS.md` 與 `AGENTS.md` | Spectra as an active authority in CODING_STANDARDS.md／AGENTS.md |
| 8 | 新增 record 的 `decision` 超過 1000 字元時 gate 只警告 | decision-length 警告含 record 路徑；CLI 以 exit 0 結束 |
