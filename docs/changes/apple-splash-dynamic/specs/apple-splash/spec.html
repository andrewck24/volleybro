apple-splash

Spec delta · ADDED 4 requirements · change apple-splash-dynamic

ADDED Dynamically generated launch screen

The system SHALL expose a route that renders a launch screen as a PNG at an exact pixel size from the request, so one handler serves every device size without stored files.

Render at the requested device size

WHEN requested with a width/height encoding a supported device’s exact resolution
THEN the response SHALL be a PNG of exactly that width and height
AND it SHALL render the “V” mark centered on a --primary background

Example — iPhone 15 Pro Max: GIVEN 1290×2796, WHEN requested for 1290×2796, THEN the PNG is exactly 1290×2796.

Reject an unsupported size

WHEN requested with a size that is not a registered device resolution
THEN the system SHALL respond 404 and SHALL NOT return an image

ADDED V mark composition

The launch screen SHALL render the “V” as two filled vector polygons reconstructed from the icon geometry, independent of any external image asset.

Mark colors and shape

WHEN the launch screen is rendered
THEN the left arm SHALL be #F6F4F5 and the right arm #FC7A56
AND the mark SHALL be vector polygons, not a raster file

ADDED Per-device startup-image registration

The app root layout SHALL register one startup image per supported device configuration, each pairing the device media query with the route URL for that device’s exact size.

Registration points at the route

WHEN the document head is produced
THEN every apple-touch-startup-image entry SHALL reference the route with the exact size
AND none SHALL reference a file under the public apple-splash directory

Device coverage spans current iPhone and iPad

WHEN the startup images are registered
THEN the set SHALL cover iPhone through the iPhone 17 generation (incl. iPhone Air) and common iPad sizes
AND every previously covered configuration SHALL remain covered

ADDED No stored splash assets

Stored Apple splash PNG files SHALL NOT be served by the application.

Static splash directory removed

WHEN the application is built
THEN the public apple-splash directory SHALL NOT contain pre-rendered splash PNGs
