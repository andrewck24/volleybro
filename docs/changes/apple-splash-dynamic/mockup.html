Root cause of the color mismatch: the icon is a rounded square (fill #0D5365). Placed on any other background, the square's edge fails to align. Using a bare V (no square) leaves no edge to misalign → the background can then use the semantic token --primary. The V is reconstructed as SVG from the icon geometry (left arm #F6F4F5, right arm #FC7A56) and does not depend on the lost vector. Once approved, design.html embeds this file via <iframe> and shows the approved draft by default.
