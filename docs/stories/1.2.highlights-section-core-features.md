### Responsive Layout System

**實作變更：響應式雙佈局架構**:

Highlights 元件採用兩套獨立的佈局系統：

**Mobile Layout (< md breakpoint)**：

```tsx
// 靜態垂直網格佈局
<div className="container mx-auto px-4 md:hidden">
  <div className="grid grid-cols-1 gap-6">
    {/* 卡片使用 landscape 比例 */}
    <HighlightCard isMobile className="aspect-[3/2] w-full" />
  </div>
</div>
```

**Desktop Layout (≥ md breakpoint)**：

```tsx
// Sticky 水平滾動動畫
<div className="sticky top-0 hidden h-screen md:flex">
  <motion.div style={{ x: springX }} className="flex gap-6">
    {/* 卡片使用原始比例 */}
    <HighlightCard className="aspect-[1/2.17] h-[45vh]" />
  </motion.div>
</div>
```

**實作重點**：

- Mobile 取消 scroll-driven 動畫，提升小螢幕使用體驗
- Desktop 保留完整 sticky + motion.js 水平滾動動畫
- 卡片比例依據設備調整：Mobile landscape vs Desktop portrait

### TDD Testing Strategy

**[Source: architecture/coding-standards.md#test-driven-development]**

TDD 開發流程：

**1. 紅燈階段（Red Phase）**：

- 先撰寫測試案例，明確定義預期行為
- 確保所有測試失敗，驗證測試的有效性
- 涵蓋正常情況、邊界情況、錯誤情況

**2. 綠燈階段（Green Phase）**：

- 實作最小可行程式碼讓測試通過
- 專注功能實現，不考慮最佳化
- 確保所有測試從失敗轉為成功

**3. 重構階段（Refactor Phase）**：

- 優化程式碼結構和效能
- 保持測試持續通過
- 改善程式碼品質和可維護性

### Testing Patterns

**[Source: architecture/coding-standards.md#testing-patterns]**

必須遵循的測試標準：

- 使用 `data-testid` 屬性進行可靠元素選擇
- 優先使用語意查詢（getByRole、getByText）
- 測試使用者可見的行為，非實作細節
- 模擬 Motion 動畫相關依賴

```tsx
// 測試範例
describe("Highlights TDD Implementation", () => {
  describe("Red Phase - Failing Tests", () => {
    it("should render four feature highlight cards", () => {
      render(<Highlights />);

      // 這些測試一開始會失敗
      expect(screen.getByTestId("highlights-section")).toBeInTheDocument();
      expect(screen.getAllByTestId("highlight-card")).toHaveLength(4);
    });

    it("should display correct feature titles and descriptions", () => {
      render(<Highlights />);

      // 測試四大特色內容
      expect(
        screen.getByText("提供簡單易用的賽事記錄工具"),
      ).toBeInTheDocument();
      expect(screen.getByText("透過強大的數據分析功能")).toBeInTheDocument();
      expect(
        screen.getByText("有效掌握球員資訊與表現變化"),
      ).toBeInTheDocument();
      expect(screen.getByText("無論是手機、平板或電腦")).toBeInTheDocument();
    });
  });
});
```
