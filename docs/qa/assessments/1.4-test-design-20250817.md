#### 1.4-E2E-002: 完整滾動互動體驗測試 (P0)

```typescript
describe("Complete scroll interaction experience", () => {
  test("should transition to glassmorphism on scroll", async () => {
    await page.goto("/");

    // Scroll down to trigger effect
    await page.evaluate(() => window.scrollTo(0, 200));

    // Wait for animation to complete
    await page.waitForTimeout(500);

    const header = page.locator("header");
    const backdropFilter = await header.evaluate(
      (el) => getComputedStyle(el).backdropFilter,
    );

    expect(backdropFilter).toContain("blur");
  });

  test("should return to transparent when scrolled back to top", async () => {
    await page.goto("/");

    // Scroll down then back up
    await page.evaluate(() => window.scrollTo(0, 200));
    await page.waitForTimeout(500);
    await page.evaluate(() => window.scrollTo(0, 0));
    await page.waitForTimeout(500);

    const header = page.locator("header");
    const backdropFilter = await header.evaluate(
      (el) => getComputedStyle(el).backdropFilter,
    );

    expect(backdropFilter).toBe("none");
  });
});
```

## Performance Tests (Risk Mitigation)

### PERF-001 緩解: 滾動效能監控

```typescript
describe("Scroll performance monitoring", () => {
  test("should maintain 60 FPS during scroll", async () => {
    const performanceObserver = new PerformanceObserver((list) => {
      const entries = list.getEntries();
      // Check frame timing
    });

    await page.evaluate(() => {
      for (let i = 0; i < 100; i++) {
        window.scrollTo(0, i * 10);
      }
    });

    // Assert FPS ≥ 50
  });

  test("should not cause memory leaks during prolonged scrolling", async () => {
    const initialMemory = await page.evaluate(
      () => performance.memory.usedJSHeapSize,
    );

    // Simulate 10 seconds of scrolling
    for (let i = 0; i < 100; i++) {
      await page.evaluate(() => window.scrollTo(0, Math.random() * 1000));
      await page.waitForTimeout(100);
    }

    const finalMemory = await page.evaluate(
      () => performance.memory.usedJSHeapSize,
    );
    const memoryIncrease = finalMemory - initialMemory;

    // Should not increase by more than 5MB
    expect(memoryIncrease).toBeLessThan(5 * 1024 * 1024);
  });
});
```

### TECH-001 緩解: 跨瀏覽器相容性測試

```typescript
describe("Cross-browser compatibility", () => {
  const browsers = ["chromium", "firefox", "webkit"];

  browsers.forEach((browserName) => {
    test(`should display correctly in ${browserName}`, async () => {
      const browser = await playwright[browserName].launch();
      const page = await browser.newPage();

      await page.goto("/");
      await page.evaluate(() => window.scrollTo(0, 200));

      const header = page.locator("header");

      // Check for backdrop-filter support or fallback
      const styles = await header.evaluate((el) => {
        const computed = getComputedStyle(el);
        return {
          backdropFilter: computed.backdropFilter,
          backgroundColor: computed.backgroundColor,
        };
      });

      // Should have either backdrop-filter or fallback background
      expect(
        styles.backdropFilter !== "none" ||
          styles.backgroundColor !== "rgba(0, 0, 0, 0)",
      ).toBe(true);

      await browser.close();
    });
  });
});
```

## Test Environment Requirements

### Unit Tests

- **Framework**: Jest with jsdom environment
- **Dependencies**: React Testing Library, Motion/React mocks
- **Coverage Target**: >90% for logic functions

### Integration Tests

- **Framework**: Jest with extended jsdom environment
- **Dependencies**: Mock IntersectionObserver, Mock useScroll
- **Coverage Target**: >80% for component interactions

### E2E Tests

- **Framework**: Playwright
- **Browsers**: Chromium, Firefox, Webkit
- **Environment**: Full development environment with animations enabled
- **Coverage Target**: All critical user paths

### Performance Tests

- **Tools**: Chrome DevTools Performance API, Lighthouse CI
- **Metrics**: FPS monitoring, Memory usage, Composite layers
- **Thresholds**: FPS ≥ 50, Memory increase < 5MB, Layers < 10
