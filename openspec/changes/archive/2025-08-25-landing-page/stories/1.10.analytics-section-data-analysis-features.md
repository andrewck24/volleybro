### Layout Specifications

根據 Epic 1.10 規格：

**AnalyticsSection 內容設計**：

1. **卡片 1 - 賽事表現比較分析**：
   - 標題：「賽事表現比較分析」
   - 描述：透過視覺化圖表比較團隊表現，找出球隊優勢
   - 展示：使用現有 Points 元件展示比賽統計

2. **卡片 2 - 深入分析球員表現（開發中）**：
   - 標題：「深入分析球員表現（開發中）」
   - 描述：運用圖表深入分析個別球員的技能表現和成長軌跡

**佈局控制**：

- AnalyticsSection: 兩個卡片都使用圖左文右佈局（`lg:flex-row-reverse`）
- 與 RecordingSection 的圖右文左佈局形成視覺對比
- 卡片高度：`lg:h-[70vh]`，展示區域 1:1 比例漸層背景
- 響應式：行動裝置自動切換為圖上文下垂直佈局（`flex-col`）

### Component Reusability Patterns

**[Source: architecture/coding-standards.md#react-component-standards]**

FeatureCard 介面已定義：

```typescript
interface FeatureCardProps {
  title: string;
  description: string;
  className?: string;
  gradientClass: string;
  children: React.ReactNode;
  testId: string;
  demoTestId: string;
  layout: "left-image" | "right-image";
}
```

- `layout: "left-image"` 對應 `lg:flex-row-reverse`（圖左文右）
- `layout: "right-image"` 對應 `lg:flex-row`（圖右文左）
- 透過 layout 屬性控制圖文佈局方向
