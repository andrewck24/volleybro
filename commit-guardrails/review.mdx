<TLDR>
commit 規則從散文變成三道檢查：`pre-commit` 只跑 lint-staged，`commit-msg` 跑 commitlint，CI 對進 `dev` 的 pull request 範圍重跑一次。trailer 檢查以分支名稱判定 Change，Fix path 改走 `hotfix/<slug>`。Changesets 的 release commit 改寫成合規格式，不為 bot 開例外。`CONTRIBUTING.md` 刪掉工具已涵蓋的 type 對照表與 `@/*` 那一行。實作沒有偏離 Proposal；Apply 期間補進 `ADR-0055` 的一條 consequence（revert 與 `fixup!` 的處理），是把「Change 分支上每個 commit 都帶 trailer」貫徹到底，不是新判斷。
</TLDR>

## 驗收結果

| # | Scenario | 結果 | 證據 |
| --- | --- | --- | --- |
| 1 | 有 subject 沒有 body 的 commit 被擋，指名 `body-empty` | 通過 | 以 `commitlint --edit` 探測；規格審查第五輪重跑 |
| 2 | Change 分支上 trailer 缺少或 slug 不符，分別報錯 | 通過 | `commitlint-plugin.test.js`「missing trailer on a Change branch…」「a trailer naming a different slug…」，兩則訊息都指向 `hotfix/<slug>` |
| 3 | `dev`、`hotfix/<slug>` 等非 Change 分支，沒有 trailer、用全新 scope 都通過 | 通過 | 同檔「no trailer on dev, hotfix/*…」；探測 `chore/x` 與新 scope |
| 4 | rebase 中 detached HEAD 時略過 trailer 規則，交給 CI | 通過 | 同檔「an empty/unknown branch (detached HEAD)…」；另以真實 `git commit` 在 detached HEAD 實測 |
| 5 | 帶 AI attribution 的 commit 被擋 | 通過 | `Co-authored-by`（不分大小寫）、`Generated-by`、行首的「Generated with/by」都被擋；slug 含 AI 名稱、散文引用這條規則、`-v` 的 diff 都不會誤擋 |
| 6 | 沒經過 hook 的 commit 在 CI 以同樣規則失敗 | 部分證明 | 本機以 `CI=true commitlint --from f17ee89b8` 跑過本分支範圍；CI job 本身要等這個 PR 才第一次執行 |
| 7 | `main` → `dev` 的 sync PR 裡的 release commit 不需例外即通過 | 通過 | 探測 `chore(release): update versions` 加 body；讀 `changesets/action` 原始碼確認 `git-cli` 模式以單一引數傳入 `git commit -m`，換行保留 |
| 8 | 新 worktree 經 `pnpm install --frozen-lockfile` 後，hook 會擋下格式錯的 commit | 通過 | 在 scratchpad 建拋棄式 worktree 實測，被擋後移除 |

## 邊界上最關鍵的一段 diff

AI attribution 檢查是這個 Change 最容易擋錯人的地方：擋得太鬆，署名就溜進 `dev`；擋得太嚴，連合法的 commit 都寫不出來。第三輪為了堵住 `Generated-by:` trailer，把「任何 trailer 的值含 AI 名稱」都當成署名，結果 slug 叫 `claude-md-bridge` 的 Change 連自己的 `Blueprint-Change` trailer 都過不了。修正是把判斷收回到「署名類的 key」與「行首的 Generated with/by」。

## 刪掉的散文

每一條都在替代它的檢查對一個刻意構造的反例失敗之後才刪。

| 刪掉的規則 | 由誰取代 | 反例 |
| --- | --- | --- |
| `CONTRIBUTING.md` 的 commit type 對照表 | `@commitlint/config-conventional` 的 `type-enum` | `notatype(x): …` 被擋 |
| `CONTRIBUTING.md`「絕對匯入走 `@/*`」 | `tsc`（`tsconfig.json` 沒有 `baseUrl`） | `from "src/lib/utils"` 報 TS2307 |
| commit 不得帶 AI attribution（commit 那一半；PR 那一半仍是散文） | `no-ai-attribution` 規則 | `Co-Authored-By: Claude` 被擋 |

scope 黑名單是 `spectra`、`openspec`、`spec-kit`、`bmad`，依據是 `eslint.config.js` 的 archive ignore、`check-workflow.js` 的 legacy adapter 與 `git log` 裡的用法。
