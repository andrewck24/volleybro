| #   | Severity    | Finding                                                                                                                                                                                                      | Resolution                                                                                                                                                                                                                      |
| --- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R3  | Suggestion  | `BodyBackdrop` 使用 `useInsertionEffect` 修改 `documentElement` / `body`。雖可達成 paint timing，但 React 將此 hook 定位為 CSS-in-JS style injection；一般 DOM side effect 使用它不符合預期 contract。       | ✅ 已修 — 改用 `useLayoutEffect`，在 DOM commit 後、browser paint 前同步 backdrop；加入 timing 註解，避免日後改成 paint 後執行的 `useEffect` 而重新產生 route color flash。                                                     |
| R4  | Test gap    | 缺少 `BodyBackdrop` 自身的 lifecycle test，未直接保護 mount 套色、`color` prop update 與 unmount restore。                                                                                                   | ✅ 已修 — 新增 direct component test，驗證 `<html>` 與 `<body>` 同步更新，並確認 cleanup 精確還原各自原有的 inline background color。                                                                                           |
| R5  | Observation | `edit-dialog-container.test.tsx` 的 warning cleanup 與 PWA backdrop 主題不同，雖屬同一批 validation-warning 整理，但 commit 內容較多元；原 test name 亦宣稱 hard navigation，超出 assertion 真正驗證的範圍。 | ✅ 已釐清 — 保留 warning cleanup 的既有 commit 分組，不重寫 history；將 test name 改為只描述 observable behavior（不呼叫 `router.back`、navigation 前 suppress leave warning），並移除不受測試直接證明的 hard-navigation 註解。 |

### Hook timing decision

`BodyBackdrop` 操作的是已 commit 的 document DOM，不是注入 stylesheet rule。採用 `useLayoutEffect` 可同時滿足兩個條件：DOM 已可安全存取，且更新發生於首次 paint 前。`useEffect` 通常在 paint 後執行，可能短暫露出前一路由顏色；`useInsertionEffect` 則保留給 CSS-in-JS infrastructure，不再用於 application-level DOM mutation。
