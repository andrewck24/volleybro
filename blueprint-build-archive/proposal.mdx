## Scope

1. 保留 `facts.json` 作為 gate snapshot。另產生 gitignored 的 lifecycle overlay，只更新網站呈現的 `archivedAt` 與 shard merge 狀態；不回寫 gate、`publishedAt`、`startedAt`、量測、Proposal／Review 或 store hash。數字繼續代表最後 gate 量測，不擴成所有統計重算。
2. 重用現有 merge／trailer landing 辨識，支援一般 merge、squash 與 Sharded Change；全部宣告 shard 落地才 archived。Converted 頁面維持原歷史；未發布 draft 不被覆寫。Overlay 綁定 store 輸入版本，不讀失敗 build 遺留的 cache。
3. Dev／build 在 store pull 後準備 overlay；依核對的 remote default 在獨立暫存 Git repository 抓取完整 integration history，固定單一 SHA、共用掃描。使用沒有 depth 限制的 fetch，確認 `git rev-parse --is-shallow-repository` 為 false，並對固定 SHA 執行 `git rev-list --parents --missing=error`，要求整個 reachable commit ancestry 可遍歷；缺 parent、shallow boundary 或無法證明完整性皆停止，不將缺資料當作未合併。Blob filtering 可節省傳輸，但不可省略 commit ancestry。不逐頁 fetch、不需要交付分支仍存在。公開 repo 只讀抓取，不新增 credential、GitHub API 或平台服務。
4. 更新共用 facts reader，讓 header、index、sidebar、previous／next 使用一致 lifecycle；publish 與 gate-frozen 檢查不讀 overlay。更新 WORKFLOW、Blueprint adapter 與直接相關 Feature；保留 G1／G2 publish，只移除合併後補日期的 publish。
5. 沿用真實 Git fixtures 與現有排序測試，依 test-audit 補未覆蓋的行為，不新增無意義測試。G2 必須有實際 Cloudflare branch build 與 rendered page 證據；本機 probe 不冒充 hosted 驗證。

不包含套件升級、app／release controller、Fast Path 擴張、store 全面遷移或他人 worktree 清理。ADR-0074／0078 僅設定 successor，不改寫原始採用理由。
