### Archive assessment 與殘留工作

最窄 Blueprint Feature 已描述 lifecycle overlay、rendered identity、按需 Preview 與 coordinated deployment；沒有 app domain vocabulary 改變，不改 CONTEXT。此 Change 是 Blueprint／CI plumbing，不改 app 行為或 contributor toolchain，沒有 app Changeset。

Code fixed point 不代表平台 activation。Hosted static-uploader 已成功；合併後正常 dispatch 是 AfterRelease 的操作義務，不偽報為已完成的 pre-merge 測試。Store 成本評估另案：文件 footprint 不等於實際 PR diff 或 token 節省，本次不刪除 store。

全面改採 `cf` 已另案追蹤，不阻擋本輪。現行 `cf --prebuilt` 能消費官方 Build Output，但封裝既有 export 的官方 writer API 尚未穩定；本次保留已 review 且 hosted upload 成功的 pinned Wrangler。下一次 deploy toolchain 升級、官方提供穩定或更直接的 static export 路徑、或 Wrangler 發生維護問題時重新評估；比較額外依賴與轉換成本，保持同一 credential 邊界及一次 build，不以工具名稱取代驗證。
